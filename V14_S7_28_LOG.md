## S2.2 Dispatcher contract

`renderControl(config)`:
- Creates `div.control-row` wrapper with `data-control-id` + `data-control-type`.
- Appends `label.control-label` from `config.label`.
- Switches on `config.type` -- delegates to the matching `create<Type>Input(config)`.
- Each create returns a `Node` or `DocumentFragment`.
- Returns assembled row, or `null` on unknown type (logged).

## S2.3 9 per-type create functions

| Type | Function | Output structure |
|---|---|---|
| slider | createSliderInput | `<input type=range>` + `.control-value` display span (id = `<id>-display`) |
| color | createColorInput | single `<input type=color>` (reserved; unused in current SETTINGS_CONFIG) |
| colorPair | createColorPairInputs | picker (pickerId) + hex text (id) as DocumentFragment |
| toggle | createToggleInput | `label.control-toggle` -> checkbox + `.control-toggle-track` |
| select | createSelectInput | `<select>` with iterated `<option>` from `config.options` |
| text | createTextInput | `<input type=text>` with placeholder |
| number | createNumberInput | `<input type=number>` with min/max/step |
| colorList | createColorListPlaceholder | comma-separated `<input type=text>` (Stage 7.29 may upgrade to swatch editor) |
| button | createButtonInput | `<button>` for the sensitivity reset action |

## S2.4 Helper
