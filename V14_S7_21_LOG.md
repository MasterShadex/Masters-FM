```html
<div class="welcome-banner" id="welcome-banner">
  <div class="welcome-banner-content">
    <span class="welcome-banner-emoji">👋</span>
    <div class="welcome-banner-text">

      <p>Start by picking a theme below, or use the Quick Settings to change the main color, size, and text size. Click "Show advanced settings" if you want fine control over everything.</p>
    </div>
    <button class="welcome-banner-dismiss" type="button">Got it, hide this</button>
  </div>

```

### Behavior
- Renders only when `localStorage.customize_welcome_seen !== 'true'`
- Dismiss button click sets `localStorage.customize_welcome_seen = 'true'` + hides banner
- Footer area gets a small "Show welcome message" link that clears the flag + re-shows the banner
- Defensive try/catch around localStorage (private browsing / WebView restrictions)

### Visual
- Stage 7.19 design tokens: `var(--surface-2)` background, `var(--r-card)` radius, `var(--sp-4)` padding
- Subtle accent-bar treatment along the top edge using `--accent-bar` gradient
- Emoji shown at left, text in middle (heading + paragraph), dismiss button at right
- Body text uses `var(--text-secondary)`; heading uses `var(--text-primary)`

## S0.7 Following-master badge spec (LOCKED per brief S0.8)

### HTML structure
Small pill-shaped badge inserted next to each of the 8 per-element accent pickers' text input + "Use accent" link:

```html
<input type="text" id="c-title-color" class="hex-in">
<span class="follow-master-badge" aria-hidden="true">Following master</span>
<button class="use-accent-link" data-target="title-color">...</button>
```

The badge is INSIDE row-ctrl, after the text input, before the "Use accent" link (which Stage 7.20 already added).

### Visual
- Pill: `background-color: var(--accent-master)` (live tracking; color updates when master changes)
- Foreground: white text via `color: #fff` with `mix-blend-mode: difference` fallback for low contrast on light master colors -- or simpler: always white text + slight text-shadow for readability
- Text: `font-size: var(--fs-tiny)` (11px), `font-weight: 600`
- Padding: 2px 6px; border-radius: var(--r-tiny)
- `aria-hidden="true"` -- decorative; screen readers announce the picker's input state via the value attribute

### Behavior (JS reactivity)
- Detected via `data-accent-following` attribute on the row OR by checking the text input value === `'var(--accent-master)'`
- Visible only when picker's current value is the sentinel string
- Hidden when user picks a hex (per-element override active)
- Re-appears when "Use accent" link clicked OR theme apply restores the sentinel OR master accent change keeps sentinel state
- Live color update: pure CSS via `background-color: var(--accent-master)` -- no JS needed for color sync since the CSS variable is set by the master accent picker handler

### Implementation strategy
- Inject 8 badges in HTML next to the 8 accent picker inputs (Stage 7.20 S0.5.A list)
- Visibility controlled by CSS class `.follow-master-active` on the badge
- A helper function `updateFollowMasterBadges()` walks all 8 accent pickers' text inputs, checks their values, and toggles `.follow-master-active` accordingly
- Hook into: bindColor input handler (per-element value change), use-accent-link click handler, applyTheme post-syncAll, master accent change handler
