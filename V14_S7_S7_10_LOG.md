## STEP 5 -- Webhook byte-equivalence verification vs PS S15

### S5.1 -- Architecture finding

Post-cutover `MastersFM_Tray.exe` (WPF C# apphost, `MastersFM_Tray_v14.dll`) does NOT invoke
`tray.ps1`. It runs its own native C# detection stack:
`SmtcEventBridge` + `DetectorOrchestrator` → `TrackResolver` → `WebhookClient`.

PS tray (csc.exe `tray_launcher.cs` host) ran `tray.ps1` in a PS runspace; `Send-WebhookAsync`
constructed the webhook JSON. The C# WPF tray uses `WebhookClient.BuildJsonPayload` instead.

### S5.2 -- Schema comparison

| Field | PS tray (S15) | C# tray | Server reads | PS compat | C# compat |
|---|---|---|---|---|---|
| artist | `artist` (string) | `artist` (string\|null) | `data["artist"]` | PASS | PASS |
| track | `track` (string) | `track` (string\|null) | `data["track"]` | PASS | PASS |
| source | `source` (string) | `source` (string) | `data["source"]` | PASS | PASS |
| positionMs | `positionMs` (long ms) | `positionMs` (double ms) | `data["positionMs"]` | PASS | PASS |
| Duration | `duration` (float, SECONDS) | `durationMs` (float, ms) | `data["duration"]` * 1000 | PASS | GAP-1 |
| Art | `trackArt` (string, omitted if null) | `art` (string\|null) | `data["trackArt"]` | PASS | GAP-2 |
| isPaused | `isPaused` (bool) | `isPaused` (bool) | `data["isPaused"]` | PASS | PASS |
| seek | `seek` (bool, heartbeat only) | not sent | `data["seek"]` | PASS | N/A |
| album/tray/observedUtc | not sent | sent | not read | N/A | ignored |

### S5.3 -- GAP impact

**GAP-1 (duration):** server reads `data["duration"]` = null -> durationMs = 0 -> DurationResolver
cascade runs for every C# tray track (adds ~0.5-2 s latency). Duration resolves correctly.
**GAP-2 (art):** server reads `data["trackArt"]` = null -> webhookArt = "" -> server cascade runs.
SMTC thumbnails from `TryExtractThumbnail` not forwarded. Art resolves correctly via cascade.
Neither gap causes overlay corruption or lost tracks; server compensates.

Recommended fix (deferred, Option A): `WebhookClient.cs` `BuildJsonPayload`: rename
`"durationMs"` -> `"duration"` (use `TotalSeconds`); rename `"art"` -> `"trackArt"`.
