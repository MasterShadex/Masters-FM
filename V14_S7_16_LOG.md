### S0.4 Customize-to-overlay binding contract

### S0.5a DEVIATION: Google Fonts CDN partial-keep

Brief S3.1 says "Remove any external font CDN `<link>` tags ... overlay.html runs inside OBS, network fetches for fonts add load delay and can fail offline."

**Conservative deviation:** the existing CDN at line 22 loads Inter + 11 Noto Sans subsets + Noto Emoji. Of these:

- **Inter** is cosmetic -- a user-selectable font choice. v14 default is Segoe UI (system font, no network fetch needed).
- **Noto Sans subsets** (SC / TC / JP / KR / Hebrew / Arabic / Thai / Symbols / Symbols 2 / Emoji) are FUNCTIONAL fallbacks for international track titles. Without them, a Cyrillic / CJK / Arabic / Thai track name renders as tofu boxes when the OS lacks coverage.

**Plan:** In STEP 3, drop ONLY the Inter portion from the CDN URL. Keep the Noto Sans + Emoji subsets. Default font becomes Segoe UI (system, no network). User-selected fonts in customize fall back to system stack if not on CDN.

Rationale: dropping international fallback fonts would silently break track-title rendering for non-Latin music sources -- a regression worse than the v12 baseline. Stage 7.16 is a visual rebuild, not a functional regression.

Documented here per ABSOLUTE RULE / S7 escape hatch ("if the v12 HTML structure genuinely won't accept v14 CSS without HTML restructuring beyond 'add a wrapper div'..."). This is the closest analogue.
