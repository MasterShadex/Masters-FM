### Item 4 -- Default-expand START HERE

**Current state** (lines 4907-4974, function `restructureSidebar`):
```javascript
const SUPERCATS = [
  { id: 'start',   label: 'Start here',  sections: ['quick-settings', 'general'] },
  { id: 'look',    label: 'Look',        sections: [...] },
  ...
];

function readCollapsed(id) {
  try { return localStorage.getItem('supercat_' + id + '_collapsed') === '1'; }
  catch (e) { return false; }
}

for (const sc of SUPERCATS) {
  const wrap = document.createElement('div');
  wrap.className = 'supercat';
  wrap.id = 'supercat-' + sc.id;
  if (readCollapsed(sc.id)) wrap.classList.add('collapsed');
  ...
}
```

**Actual current behavior:**
- localStorage key: `supercat_<id>_collapsed` (e.g. `supercat_start_collapsed`)
- When key is `'1'`: `.collapsed` class is added (rendered collapsed)
- When key is `'0'`, missing, or any other value: no `.collapsed` class (rendered expanded)
- **Default for ALL supercats: EXPANDED** (no first-load collapse). The brief's STEP 0 mentions "screenshot showed ALL supercats collapsed on first load" which suggests operator's localStorage was populated from a prior session with `'1'` for each supercat -- not a Stage 7.21 default behavior.

**START HERE actual id:** `start` (used in localStorage key `supercat_start_collapsed`; HTML id `supercat-start`). Brief used placeholder `start-here`; correcting to `start` per actual code.

**Target** (S0.6 lock + S4 implementation):

Even though current default is already expanded, the brief asks for explicit START HERE handling for code clarity + future-proofing. Implementation:

```javascript
for (const sc of SUPERCATS) {
  const wrap = document.createElement('div');
  wrap.className = 'supercat';
  wrap.id = 'supercat-' + sc.id;
  // Stage 7.24: START HERE explicitly defaults to expanded on first load
  // (when no localStorage entry exists). Other supercats keep the implicit
  // default (also expanded) via readCollapsed returning false when key missing.
  const stored = localStorage.getItem('supercat_' + sc.id + '_collapsed');
  if (stored === '1') {
    wrap.classList.add('collapsed');
  } else if (stored === null && sc.id === 'start') {
    // Explicit: first-time users see Quick Settings + General immediately.
    // No action needed (no .collapsed class added) -- this branch documents intent.
  }
  // else (stored === '0' or any other value): no .collapsed class, render expanded.
  ...
}
```

The behavior is identical to the current code, but the explicit `else if` branch documents the design intent: "START HERE defaults to expanded for first-time users." This prevents future refactors from inadvertently changing first-load behavior.
