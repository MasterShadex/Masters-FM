```css
.control-row {
    display: flex;
    flex-direction: column;
    gap: var(--s-2);             /* 8px label-input gap inside row */
    padding: var(--s-3);         /* 12px all sides; main density driver */
    border-radius: var(--r-md);
    margin-bottom: var(--s-1);   /* 4px between rows */
}

    background: var(--c-surface-elevated);   /* #2e2e2e */
}

    padding: var(--s-2) 0;       /* 8px top/bottom */
}
```

Tokens in play:
- `--c-surface: #242424` (the supercat-body background)
- `--c-surface-elevated: #2e2e2e` (used by control-row hover + welcome/topbar)
- `--s-1: 4px`, `--s-2: 8px`, `--s-3: 12px`, `--s-4: 16px`

`.control-row` has NO background by default (transparent over the supercat-body
which sits on the sidebar). Labels (pure white per Stage 7.24) sit on the
sidebar's `--c-surface` = `#242424` -- that's the "white on grey contrast
weak" complaint.
