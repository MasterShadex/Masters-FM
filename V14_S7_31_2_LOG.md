## S0.5 Override design (DEFAULT-SAFE, opt-in, lives OUTSIDE the build)
Add `ResolveBaseRepo()` + make ManifestUrl computed:
```
private const string DefaultBaseRepo = "MasterShadex/Masters-FM";   // production default (UNCHANGED string)
private static readonly Regex _repoRe = new(@"^[A-Za-z0-9._-]+/[A-Za-z0-9._-]+$", RegexOptions.Compiled);

private static string ResolveBaseRepo() {
    try {
        var env = Environment.GetEnvironmentVariable("MASTERSFM_UPDATE_BASE_REPO");
        if (!string.IsNullOrWhiteSpace(env) && _repoRe.IsMatch(env.Trim())) return env.Trim();
        var ovr = Path.Combine(LocalAppData, "MastersFM", "updater_override.json");
        if (File.Exists(ovr)) {
            var repo = JsonNode.Parse(File.ReadAllText(ovr))?["baseRepo"]?.GetValue<string>();
            if (!string.IsNullOrWhiteSpace(repo) && _repoRe.IsMatch(repo.Trim())) return repo.Trim();
        }
    } catch { /* any error -> safe default */ }
    return DefaultBaseRepo;
}
private static string ManifestUrl => $"https://raw.githubusercontent.com/{ResolveBaseRepo()}/main/version.json";
```
- DEFAULT-SAFE: no env var AND no override file -> DefaultBaseRepo -> byte-identical to today.
- The override VALUES (env var / %LOCALAPPDATA%\MastersFM\updater_override.json) live on the dev
  machine only -> can NEVER ship. The resolver CODE ships but is inert without an override.
- Regex-validated owner/repo (else default) -> no URL injection.
- SECURITY: even if redirected, the cert PIN (thumbprint+pubkey) + SHA256 gate still gate the
  install -> a foreign repo's MSI (not signed by MasterShadex) is REJECTED. The override changes
  WHERE it looks, never WHAT it accepts. (Writing the override file already requires local write.)
- Local-file mechanism is what enables the on-boot trigger test (a relaunched tray reads it at
  startup); env var supports quick in-process manual/hourly tests.
