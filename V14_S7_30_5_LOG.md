## S0.3 RESEARCH -- legacy pmExport (Item 1), customize_legacy.html line 5068

Legacy export design = **B: export a SAVED preset by name** (NOT current config).
- `pmExport(name)` fetches `GET /load-preset?name=<encoded>` -> nested config.
- Wraps in an ENVELOPE:
  - `format`: "mastersfm.preset"
  - `version`: 1
  - `name`: "<preset name>"
  - `exportedAt`: "<ISO timestamp>"
  - `exportedFrom`: "v9.6.3"
  - `config`: { ...nested config... }
- Filename: `MastersFM_<safeName>.json` where
  `safeName = name.replace(/[^a-zA-Z0-9 _\-]/g,'').trim() || 'preset'`.
- Download: `Blob([JSON.stringify(envelope, null, 2)], 'application/json')` ->
  `createObjectURL` -> `anchor.click()` -> `setTimeout(revokeObjectURL, 0)`.
- Client-side download, BUT makes 1 server call to fetch the saved preset first.
- Status via `pmStatus("Exported ...", true)`.

## S0.4 RESEARCH -- legacy pmImport (Item 2), customize_legacy.html line 5099

- `#pm-import-btn` (button) + `#pm-import-file` (`<input type=file>`).
- btn click -> `importFile.click()`; file change -> if `files.length`:
  `pmImport(files[0])`; then `importFile.value = ''` (reset for re-import).

`pmImport(file)`:
- `await file.text()` -> `JSON.parse` in try/catch -> on parse error:
  `pmStatus("File is not valid JSON", false)`; return.
- FORGIVING format detection:
  - envelope: `parsed.format === 'mastersfm.preset' && parsed.config`
    -> name = `parsed.name`, cfg = `parsed.config`.
  - bare object: cfg = `parsed`, name = filename (strip `.json` + `MastersFM_`).
  - else: `pmStatus("doesn't look like a preset", false)`; return.
- Sanitize name (regex, slice 64); de-conflict (" (2)", " (3)" if taken).
- Sanity check: `typeof cfg === 'object' && !Array.isArray(cfg)` else reject.
- Then **POST /save-preset {name, config}** -- legacy SAVES the import to the
  server (server deepMerges with DEFAULTS, so partial presets fill in). Then
  `pmStatus("Imported as X -- click Load to apply it")`. **Does NOT applyConfig
  directly.**
- Error handling: all failures via pmStatus; outer try/catch, no throw escapes.
